## Evidence boundaries

- **Shipped/tested:** only code in the published Codex, OpenCode, Aider, and Goose release commits above is used as release evidence. T3 is pinned to the explicitly requested studied revision.
- **Experimental:** Codex fields annotated `#[experimental(...)]` (for example resume history/path/initial-page options) are not treated as stable contracts. Piss only borrows the lifecycle/precondition pattern.
- **Design documents and issues:** none are used as implementation evidence in this matrix.
- **Piss authority boundary:** Pi’s transcript remains the model source of truth. Piss history is a durable, transport-oriented UI projection and may be reconstructed from the transcript when projection storage is absent.
